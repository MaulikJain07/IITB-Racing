# IITB-Racing

This repository contains my work across multiple modules of the IITB Racing driverless/autonomous stack — spanning perception, SLAM, ROS2 systems, algorithms & data structures, and assorted assignments completed as part of the team's training and evaluation process.

## Module Overview

### Perception

A progressive set of tasks building up a cone-detection pipeline for the autonomous racing stack:
- **Task 1** — Introductory computer vision task working with a sample cone image.
- **Task 2** — Implementing and visualizing 2D convolution operations (single and dual kernel), core to understanding CNN mechanics.
- **Task 3** — Training/using a YOLOv11s model for cone detection.
- **Task 4** — Applying the detection pipeline to a custom recorded track, with a standalone `cone_detector.py` and a corresponding ROS2 C++ package (`cpp_perception_task4`) for real-time inference.

### SLAM

Early SLAM-focused work, starting from the probabilistic foundations (normal distributions and their role in localization/filtering) that underpin approaches like the Kalman and Particle filters used in full SLAM pipelines.

### ros2_ws

A ROS2 (colcon) workspace containing:
- Custom packages: `handshake_assignment`, `shm_simulator`, `py_pubsub`, `first_robo`, `cpp_perception_task4`
- Reference/example packages used while learning ROS2 concepts (publishers, subscribers, executors, actions, services)

> Note: `build/`, `install/`, and `log/` inside this workspace are auto-generated by `colcon build` and are intentionally excluded from version control — see `.gitignore`.
